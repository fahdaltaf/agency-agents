How to Use Agency Agents

1 Using in Claude Code

Click "Copy Prompt" on any agent card, and save it into your project's custom prompt directory or paste it into your prompt instructions:

mkdir -p .claude/prompts
# Paste the downloaded agent markdown into .claude/prompts/agent-name.md

2 Using in Cursor / Windsurf

Add the agent persona directly to your .cursorrules or `.cursor/rules` folder:

mkdir -p .cursor/rules
# Save persona as .cursor/rules/agent-name.md

3 Using in Antigravity

In Antigravity, you can copy the agent prompt or define it as a subagent or skill within your workspace.
